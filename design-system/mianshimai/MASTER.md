# 面试麦 · 招聘季设计系统

采用 UI/UX Pro Max 的招聘产品、海报排版与清晰交互原则，针对校园招聘场景设计。视觉以大标题、贴纸插画、明快配色、细描边和少量硬阴影组成；不使用没有依据的录取率或用户量来制造吸引力。

## 双季主题

| 用途 | 秋招 | 春招 |
| --- | --- | --- |
| 主题亮色 | 暖橙 #fa8850 | 嫩绿 #cbe67f |
| 浅底色 | 奶油色 #fffbf5 | 浅绿白 #f8fbf1 |
| 浅强调底 | #ffe9d6 | #e6f0d0 |
| 深强调文字 | #a93e13 | #315924 |

| 辅助贴纸 | 淡紫、浅蓝 | 浅蓝、粉色 |
| 季节图案 | 枫叶 | 花朵 |
| 季节微动效 | 枫叶短暂飘动 | 花朵短暂舒展 |

亮橙与嫩绿按钮使用深色文字。需要白字的小按钮使用 primary-600 等深色层级。中性文字和边框独立于业务成功、错误等语义颜色。

主题以 CSS 变量集中管理，Tailwind 的 primary、paper、ink、muted、line、accent 引用这些变量；登录、准备页和账户工作区也能随主题变化。样式入口为 `apps/web/src/app/globals.css` 和 `tailwind.config.js`。

## 招聘季规则与维护

- 默认跟随时节，按 Asia/Shanghai 时区：2–6 月为春招；7 月至次年 1 月为秋招及补录。
- 首页顶部可选择跟随时节、秋招季、春招季；手动偏好保存在本地，不上传服务器。
- 根布局 SeasonProvider 共享当前主题，跨页面保持一致；每分钟及页面恢复可见时检查季节。
- 日期规则、主题文案统一在 `apps/web/src/lib/recruitment-season.ts`。调整活动档期时同步其单元测试，不要在各页面分别判断月份。
- 插画在 SeasonArtwork 中使用 CSS/SVG 绘制，不依赖远程图片。Offer 票据是装饰，不能当成用户真实录用结果。

## 页面结构

1. 海报式首屏：招聘季文案、主按钮、简历与 Offer 票据插画、主题选择器。
2. 三类练习：押题、专项模拟、行测与 HR；使用三种辅助色和文件、对话图案。
3. 互动示例：用户切换岗位、查看静态反馈；明确标注示例，不调用模型。
4. 复盘价值：结构化建议的示意图，不显示虚构分数或实际用户报告。
5. 三步开始与招聘季行动区。

保留 Inter 与中文系统字体回退，不增加字体包。桌面内容最大 1200px；手机左右留 20px。首屏中文标题 36–59px，输入框 16px，正文 14–16px。海报装饰允许旋转，正文及主要操作保持平直清晰。

## 动效与可访问性

- 枫叶动画共 4.8 秒、花朵共 3.8 秒，随后停止；气泡只在入场时出现，不自动轮播或持续闪烁。
- `prefers-reduced-motion` 关闭装饰动画，弱化过渡。
- SVG 装饰不抢占键盘焦点；插画整体有文字说明，图标控件提供名称。
- 主要按钮至少 44px；键盘焦点清晰；选择状态使用 aria-pressed，原生 dialog 支持 Escape 和焦点返回。
- 加载、空列表与失败分别呈现；用户可重试，失败不能伪装为空数据。
