# 产品待升级清单

**状态：仅记录，暂不启动。** 本清单是需求备忘，不是开发任务或已排期计划。所有条目均未启动；新增记录不触发开发、部署、定时任务或第三方服务调用。后续由用户明确选择要启动的条目，再细化范围和验收标准。

## 用户提出的方向

### UPG-001 面经广场

让用户浏览和分享面试经历，既包括线下面试、企业线上面试，也包括在面试麦完成的模拟练习。

- 区分“用户分享的实际面试经历”和“平台模拟面试记录”，在列表和详情显著标注来源；用户自述不等于平台已经核验真实性。
- 实际面经可填写公司、岗位、招聘季、面试轮次、题目、个人回答、结果和心得。
- 平台面经由用户从自己的练习与复盘中选择内容、预览后发布，不自动公开简历、完整对话或录音。
- 支持按公司、岗位、轮次及来源筛选，以及搜索、收藏、评论、匿名展示、举报和本人删除。
- 收藏题目可以带入个人练习，形成“看面经 → 练问题 → 写复盘”的连接。

### UPG-002 简历编辑器完善

让用户在平台内编辑、排版、保存并导出自己的简历。

当前已有在线简历基础编辑入口，提供基本信息、教育和工作经历表单；预览仍以结构化数据展示为主。本条记录的是完善现有编辑器，不另建一套重复实现。

- 补齐项目经历、技能、校园经历和自定义模块，支持模块排序。
- 提供正式版式预览、模板选择、分页检查与 PDF 导出。
- 自动保存需要展示保存中、已保存和失败重试状态，并保留版本记录。
- 支持针对不同岗位维护简历版本，进入面试时选择对应版本。
- AI 建议以可审阅的修改建议呈现，由用户决定是否采纳；保留事实，不替用户编造经历和成绩。
